# Camera-source V1 bounded lifecycle recovery

Declare before the first pilot. For each phase/scale allow at most TWO isolated
server attempts total: the original plus one same-source/plan/budget replacement.
A replacement is permitted only after0-RGB readiness/RPC failure, or complete
capture with client0/clean cleanup but server shutdown exit-9/forced-stop.
This annex authorizes no model/GT/pose/image-quality driven recapture.

Before that single replacement write a per-run record of the original server/
capture SHA, failure condition, source freeze SHA, unchanged180/900/30 budgets,
scale/phase and replacement index. Preserve original failure and all raw hashes;
never mark its shutdown accepted. Only a normal exit130 can supply accepted GT
or model probes. No retry after the replacement. If a pilot remains failed,
retain it as technically rejected; no model inference on its images. The640
control must pass for a complete comparison. A failed comparison remains failed.
This does not claim a lifecycle stability fix or broaden live acceptance.
