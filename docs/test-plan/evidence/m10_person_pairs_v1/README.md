## 같은 보행자에서 가림 유무를 비교한 결과

Town02에서 단독 장면과 이륜차 뒤 장면 모두 평가 크기를 충족한 보행자 관측은 14쌍이었다. 기존 모델은 단독일 때 14/14를 찾았고, 이륜차 뒤에서는 4/14를 찾았다. 점수 보정 후보도 같은 10쌍을 놓쳤다. 승용차 뒤와 단독을 비교할 수 있는 16쌍에서는 가림 장면 정검출이 11건에서 12건으로 늘었다. 30m 이상 보행자는 세 장면 조건을 합쳐 30건이었고, 정검출은 17건에서 18건으로 늘었다. 분모는 반복 촬영한 관측 수다. [대응 관측 및 오검출 재검산](fp-pairs.json)

새 검증에서 사람 오검출 15건 중 11건이 보행자와 이륜차가 함께 있는 24장에 집중됐다. 기존 검증에서는 추가 출력이 만든 오검출 22건 중 17건이 실제 사람 박스와 조금 겹쳤지만 IoU가 0.10 이상 0.50 미만이었다. 보정 후보가 새 검증에서 놓친 보행자 15건 중 13건은 정답과 IoU 0.50 이상인 후보 박스가 점수 보정 입력에 있었다. [기존 검증 오검출 분류](fp-archive.json) · [누락 및 장면별 결과](comparison.json)

다음 실험은 이륜차 뒤의 보행자와 탑승자에 각각 하나의 박스를 대응시킨다. 학습 도로에서 한 사람의 일부만 덮는 박스와 같은 사람을 두 번 감싸는 박스를 오답으로 사용하고, 위치가 정확한 박스를 우선 선택하는 후보를 비교한다. 비교에는 사람별 일대일 검출과 사람 오검출을 함께 사용한다.

## 촬영과 평가 방법

각 지도에서 두 도로, 네 거리(20·31·34·38m), 세 가지 시점·날씨 조합을 사용했다. 각 조합은 보행자 단독, 승용차와 보행자, 승용차 단독, 이륜차와 보행자, 이륜차 단독의 다섯 장이다. 2560×1536 RGB와 같은 프레임의 인스턴스 마스크를 120장씩 촬영했다. 240개 원본 마스크에서 정답을 재생성하고 RGB 해시 2,400개(새 영상 및 기존 학습·검증 전체)의 분할 간 중복을 검사했다. 실제 보행자 픽셀 면적이 단독 대비 10~90% 감소하고 평가 크기를 충족한 검증 관측은 승용차 뒤 16건, 이륜차 뒤 14건이었다. [학습 가시성](visibility-train.json) · [검증 가시성](visibility-validation.json)

학습은 Town01 도로 4·10과 기존 학습 1,461장을 사용했다. 최초 검증 지도 Town07은 설치된 CARLA에 지도 본체가 없어 촬영 전에 종료했다. 학습한 가중치를 고정하고 검증 영상을 열기 전에 Town02 도로 12·19를 선택했다. 이전 Town02 촬영 도로와 겹치지 않고 가장 가까운 기존 카메라 위치와 58.38m 떨어져 있다. 장소 101을 다시 평가하거나 새 보류 장소를 소비하지 않았다. [촬영 및 서버 종료 기록](capture.json)

보정기는 고정된 D-FINE의 후보별 특징 256개로 사람 점수를 보정하며, 판정 기준은 0.60이다. 기존 검출을 유지하고 추가 후보를 검사했다. 사람 오검출의 허용 증가량은 새 검증 1건, 기존 검증 6건이며, 사람 정밀도 하한은 85%다. [학습 가중치 및 입력 식별자](person-head.json)

## 재현

저장소 루트의 `build/m10-person-pairs-v1`에 원본 RGB·압축 마스크와 특징 캐시가 있다. 이 폴더를 보존하면 동일 자료를 다시 평가할 수 있다. 각 지도의 계획과 프레임별 라벨·RGB·마스크 해시는 이 문서 옆의 압축 JSON에도 보존했다. 다음 명령은 로컬에 보존된 자료를 사용한다.

```bash
out=build/m10-person-pairs-v1
src=tests/integration/perception
py=build/m10-perception/cuda-venv/bin/python
export PYTHONPATH=. OPENBLAS_NUM_THREADS=1
build/m10-training-v1/venv/bin/python "$src/person_pair_candidate.py" instrument "$out"
for split in train validation; do
  "$py" "$src/person_pair_review.py" "$out" "$split"
  "$py" "$src/person_pair_candidate.py" cache "$out" --split "$split"
  "$py" "$src/person_pair_candidate.py" cache "$out" --split "$split" --paired
done
"$py" "$src/person_pair_candidate.py" fit "$out"
"$py" "$src/person_pair_candidate.py" evaluate "$out"
"$py" "$src/person_pair_errors.py" "$out"
"$py" "$src/person_pair_errors.py" "$out" --paired
```
