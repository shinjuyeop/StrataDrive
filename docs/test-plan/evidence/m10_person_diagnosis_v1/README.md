# M10 보행자 누락 진단

학습 1,461장과 검증 699장에서 고정한 D-FINE의 사람 판정을 추적했다. 검증에서 놓친 보행자 5건은 모두 가림 장면이었다. 네 건은 정답과 충분히 겹치는 박스가 있었지만 사람 점수가 0.60 미만이었고, 한 건은 300개 후보 중 정답과 충분히 겹치는 박스가 없었다. 기존 보류 장소 101은 재생하지 않았다. [전체 집계](summary.json) · [프레임별 판정](frames.jsonl.gz)

| 자료 · 사람 유형 | 검출 / 정답 | 위치가 맞지만 점수 미달 | 위치가 맞는 박스 없음 |
| --- | ---: | ---: | ---: |
| 학습 · 보행자 | 151 / 169 | 15 | 3 |
| 학습 · 탑승자 | 268 / 292 | 24 | 0 |
| 검증 · 보행자 | 55 / 60 | 4 | 1 |
| 검증 · 탑승자 | 85 / 101 | 16 | 0 |

검증의 가림 장면에서 보행자는 4/9, 가림을 제거한 참조 장면에서는 9/9를 검출했다. 원거리로 분류된 장면에서는 보행자 12/12, 탑승자 15/24를 검출했다. 검증 보행자 60건 중 카메라와의 거리가 30m 이상인 관측은 0건이다. 장면의 ‘원거리’ 분류와 실제 미터 단위 거리 구간은 서로 다른 집계다. 다른 정답 박스가 보행자 박스 면적의 25% 이상을 덮은 경우는 2/7, 나머지는 53/53이었다. 이 면적은 2차원 박스 교집합으로 측정했다. 관측 수에는 같은 장면 구성의 다른 날씨·시점이 포함된다.

## 점수 기준과 디코더 비교

| 사람 점수 기준 | 검증 보행자 / 60 | 검증 탑승자 / 101 | 검증 사람 오검출 |
| --- | ---: | ---: | ---: |
| 0.60 (현재) | 55 | 85 | 3 |
| 0.50 | 55 | 90 | 6 |
| 0.40 | 56 | 93 | 7 |
| 0.35 | 56 | 94 | 10 |

같은 출력에 0.35를 적용하면 사람을 10건 더 찾지만 그중 9건은 탑승자다. 검증 보행자 누락 5건 중 3건은 위치가 맞는 모든 박스의 사람 점수가 0.35에도 미달했다. 기존 그래프 안의 원본 D-FINE 디코더도 0.60에서 비교했다. 원본 디코더가 추가로 찾은 탑승자는 7건이지만, 현재 후보가 찾은 보행자 4건을 잃었고 보행자 누락 5건을 하나도 회복하지 못했다. 사람 전체 오검출은 3건에서 6건으로 증가했다.

다음 실험은 30m 이상 보행자와 부분 가림·이륜차 중첩 보행자를 별도의 개발 장소에서 수집한다. 같은 배경·거리에서 가림 유무를 짝지어 촬영하고 학습 장소와 검증 장소를 나눈다. 먼저 기존 0.60 기준으로 취약 조건을 재현한 뒤 위치가 맞는 박스의 사람 점수를 개선하는 후보 하나를 비교한다. 보행자·탑승자별 정검출과 사람 오검출을 함께 검사하고, 개선 후보를 고정한 뒤 새 독립 장소에서 최종 판정한다.

## 재현

고정 모델 복사본의 출력에 상위 300개 선택 전의 박스·80개 클래스별 점수·선택 인덱스를 추가했다. 원본 RGB를 해시로 확인해 그래프에 입력하고, 매 프레임에서 인덱스로 복원한 클래스·박스·점수가 실제 선택 결과와 일치하는지 검사했다. 이미지 경계로 자른 박스에 IoU 0.5와 기존 평가기의 일대일 대응을 적용했다. 상위 300개 순위 절단과 일대일 경쟁으로 분류된 누락은 두 분할 모두 0건이었다. 검증 두 집단 각각의 현재 사람 정검출·오검출·누락 건수는 기존 동결 기록과 일치했다. [동결 검증 기록](../m10_parking_verifier_v1/selected/validation.json)

저장소 루트에서 원본 자료와 CUDA 환경을 사용한다. 거리 계산은 인스턴스 ID로 연결한 카메라와 배우 위치 사이의 3차원 거리다. Town03은 촬영 시 기록한 위치를, 추가 지도 자료는 생성 계획의 위치를 사용했다. 학습·검증 영상과 가중치는 기존 로컬 실험 묶음에 보관한다.

```bash
out=build/m10-person-diagnosis-v1
script=tests/integration/perception/person_proposal_diagnosis.py
mkdir -p "$out"
build/m10-training-v1/venv/bin/python "$script" instrument "$out"
PYTHONPATH=. build/m10-perception/cuda-venv/bin/python "$script" run "$out"
build/m10-perception/cuda-venv/bin/python "$script" summarize "$out"
```
