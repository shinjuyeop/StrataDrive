# M10 버스 재현율 개선과 새 도로 평가

## 버스가 사라진 단계

기존 후보를 장소 307에서 놓친 다섯 장에 그대로 재생했다. 다섯 장 모두 원래 디코더의 버스 박스가 정답과 IoU 0.5 이상으로 일치했고, 버스 신뢰도는 0.673~0.826이었다. 적응 디코더가 같은 위치에 부여한 트럭 점수는 0.207~0.368이었다. 기존 후처리는 이 점수가 0.20 이상이면 버스 박스를 삭제했다. 원거리 세 장과 근거리 두 장 모두 후처리가 끝나면 버스 출력이 0건이었다. [기존 모델의 프레임별 점수](predecessor.json)

별도 학습 자료 1,461장의 버스 누락 15건 중 10건에서 같은 트럭 차단 조건을 재현했다. 나머지 5건은 위치가 맞는 원래 버스 박스의 신뢰도가 낮았다. 두 디코더의 버스 관측을 모두 사용하는 첫 후보는 개발 자료 중 Town02의 버스 오검출을 0건에서 9건으로 늘려 기각했다. [첫 학습 선택](first/selection.json) · [기각한 후보의 검증](first/validation.json)

## 수정과 개발 결과

기존 버스를 먼저 유지하고, 중복되지 않는 추가 버스 박스만 검토한다. 새 박스 점수가 0.60 이상이고, 같은 위치에서 두 디코더의 버스 지지가 각각 0.35 이상이며, 적응 디코더의 트럭 점수가 0.30 미만일 때 복구한다. 기존 ONNX와 사람 확대 규칙을 그대로 사용했다. [선택값](selection.json) · [개발·평가 절차](protocol.json)

버스 정답이 없는 기존 검증 영상 640장을 두 번째 선택의 오검출 보정에 사용했다. 따라서 아래 699장은 개발 결과로 집계한다. 699장 전체에서 버스 검출은 46/59에서 49/59로 늘었고 버스 오검출은 두 후보 모두 0건이었다. 별도 개발 장소 90의 81장에서는 6개 클래스 절대 기준과 YOLOX-S 상대 기준을 통과했다. [개발 699장](validation.json) · [개발 장소 90](evaluation-development-01-score.json)

새 평가 장소는 Town04 원본 도로 지도의 10m 간격 차로 지점에서 기존 도로들을 제외해 선택했다. 장소 번호 492는 이 격자의 식별자다. 도로 8, 차로 -1이며 기존 카메라와의 최소 거리는 87.5m였다. 모델을 사용하지 않은 준비 영상 99장의 가시성 검사를 통과한 뒤 81장의 평가 조건을 고정했다. [사전 등록](nomination.json)
