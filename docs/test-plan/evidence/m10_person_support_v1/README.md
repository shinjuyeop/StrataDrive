# M10 가려진 사람 검출과 확대 영상 선택

기존 D-FINE 모델로 원본 전체와 이륜차 주위 확대 영상을 처리한다. 확대 결과에서만 새로 찾은 사람이 너무 작으면 그 프레임에는 원본 전체 영상의 사람 검출을 사용한다. 사람별로 유리한 결과를 골라 합치지 않고 두 관측과 선택 근거를 모두 기록했다. 사람 이외의 클래스는 전체 영상에서 검출한다.

Town01 학습 120장으로 640×384 좌표에서 짧은 변 4픽셀, 면적 25픽셀을 선택했다. 두 관측의 사람 박스가 IoU 0.5 이상으로 겹치면 작은 사람도 확대 결과에 유지한다. 학습 120장의 보행자·탑승자 동시 검출은 1/14에서 10/14로 늘었고, 사람 오검출은 1건에서 2건이 됐다. 후보와 기준은 검증 전에 커밋 `c90b862b`에 고정했다. [선택 규칙](protocol.json) · [학습 결과](selection.json)

| --- | ---: | ---: | ---: | ---: |
| 기존 699장, 전체 영상 → 새 후보 | 55/60 → 55/60 | 85/101 → 87/101 | 해당 없음 | 3 → 1 |
| Town02 120장, 전체 영상 → 새 후보 | 30/46 → 35/46 | 46/48 → 46/48 | 3/14 → 8/14 | 3 → 4 |

Town02에서 조건 없이 확대 결과를 쓰면 동시 검출 11/14와 오검출 9건이었다. 새 후보는 8장에서 원본 전체 관측으로 돌아갔다. 이 과정에서 평가 대상 보행자 3건을 놓쳤고, 평가 크기에 미달한 작은 사람 5건이 오검출에서 빠졌다. 남은 오검출 4건도 실제 작은 사람 마스크와 겹쳤으며, 4건 모두 원래 기준에 따라 오검출로 계산했다. [검증 집계](validation.json)

개발 장소 90의 2560×1536 영상 81장 전체에서 6개 클래스 정답 534개 중 430개를 찾았고 오검출은 10건이었다. 사람 재현율은 32/42(76.19%), 가장 낮은 클래스 재현율은 73.33%였다. 기존 절대 기준과 같은 영상의 YOLOX-S 대비 상대 기준을 모두 통과했다. [개발 채점표](evaluation-development-01-score.json) · [프레임별 출력](development-detections.json.gz)

새 Town05 도로 1·3에서 24개 배치를 다섯 가지 조건으로 촬영한 120장을 전부 평가했다. 보행자는 30/52에서 37/52로 늘었지만 탑승자는 47/48에서 43/48로 줄었고, 엄격한 사람 오검출은 1건에서 3건으로 늘어 상한 2건을 넘었다. 원본 관측을 확대 관측으로 대체하는 후보를 기각했다. 재시작 전의 미완료 영상 6장과 새 영상의 동일 RGB는 0장이었다. [새 도로 결과](fresh.json) · [오검출·손실 재검산](support-audit.json)
