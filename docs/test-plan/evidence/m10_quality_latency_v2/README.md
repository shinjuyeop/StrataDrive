# M10 차량 재검사 최적화와 100ms 지연

기존 RTX 3090 검출기의 클래스·박스·점수를 유지하면서 원본 BGRA에서 검출까지의 전체 p95를 115.8ms에서 94.49ms와 94.55ms로 줄였다. 독립 프로세스 두 개를 차례로 실행해 같은 2K 평가 영상 891장을 각각 처리했다. 두 번 모두 11개 장소에서 절대 기준 9개와 YOLOX-S 상대 기준 6개를 통과했다. ## 변경과 검증

- 차종이 충돌할 때는 이미 GPU에 있는 2K 영상에서 같은 범위를 잘라 두 모델에 직접 입력했다. 같은 승용차와 겹치는 트럭들이 한 프레임의 판정을 공유한다. 외형 점수와 가능한 최대 지역 점수로도 제거 기준에 도달할 수 없으면 해당 확대를 생략한다. 도로 7의 실제 승용차 영역 24개에서 기존 경로와 36개 특징값·분류 확률을 대조했고 모든 값이 일치했다. [영역별 대조](conflicts.json)
- 작은 승용차는 서로 다른 확대 창 두 개의 동의가 필요하다. 먼저 일부 창을 읽어 남은 창끼리는 서로 겹치지 않게 했다. 어느 창이 높은 점수의 짝을 만들 수 있는지 확인한 후, 낮은 점수 박스가 기존 크기 중앙값 판정에 영향을 줄 수 있는 창까지 확인한다. 동점의 순서도 복원한다. 배율마다 가장 가까운 창 하나씩만 확인한 초기안은 도로 55에서 158/198개(79.80%)로 재현율 기준 80%에 미달했다. 채택한 후보는 이 도로에서 이전과 같은 160/198개(80.81%)를 검출했다.
- BGRA를 재사용 RGB 버퍼에 변환하고, 기존 트리 분류와 탑승자·확대 박스 비교를 컴파일했다. 1,024개 창 조합, 낮은 점수 박스가 걸친 경계, 탑승자 융합 동등성 등을 포함한 인지 회귀 테스트 664개가 통과했다.

이전 5분 Host 동시 실행에서 장면 생성부터 카메라 콜백까지 중앙값은 38.2ms였다. 이를 고정 비용으로 가정하면 검출에 쓸 수 있는 시간은 61.8ms이고, 이번 891장 중 각각 152장과 147장이 그 안에 들었다. 서로 다른 실행을 이용한 여유 시간 계산이며 실제 수용률은 동시 실행으로 측정해야 한다. [이전 카메라 전달 측정](../m10_cuda_resize_v1/latency-300s.json)

## 측정 범위와 재현

영상당 시간은 메모리에 있는 BGRA를 읽기 직전부터 여섯 클래스의 최종 박스를 반환할 때까지다. 기준은 엄격하게 100ms 미만이다. 각 실행은 개발 324장에 이어 평가 891장을 순서대로 처리했다. 첫 개발 프레임은 각각 2936.4ms와 392.6ms였으며 개발 분할에 포함했다. 평가 분포는 모델이 이미 실행 중인 조건이다. 원본 압축 해제·해시 계산, 카메라 취득·전달·제어기 수용은 이 시간 범위 밖이다. Host 동시 실행에서 실제 기한 내 수용과 Jetson AGX Thor·Orin NX 개별 성능 측정이 남았다. [실제 입력 기한](../../../interfaces/perception-async-native-v1.md)

이전 실험과 같은 ONNX·TensorRT 엔진·전처리 라이브러리를 사용했다. 기록된 두 실행의 소스와 엔진 식별값은 집계 파일에 있다. 동일한 모델·2K 원본과 빌드가 준비된 저장소에서 새 경로로 다음 명령을 실행한다. [엔진 빌드 환경](../m10_quality_latency_v1/README.md#재현) · [재생](../../../../tools/m10_quality_latency.py) · [결과 대조](../../../../tools/m10_quality_latency_audit.py)

```bash
export PYTHONPATH=tools:tests/integration/perception:.
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
py=build/m10-perception/cuda-venv/bin/python
v1=build/m10-quality-latency-v1

  "$py" tools/m10_quality_latency.py "$w/$run" --mode targeted \
    --library "$v1/quality_crop_v2.so" --engine "$v1/dfine-fp16.plan" || exit 1
done
"$py" tools/m10_quality_latency_audit.py "$w/new-comparison" "$w/new1" "$w/new2"
```
