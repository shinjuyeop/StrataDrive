Town02에서 보행자와 탑승자를 함께 찾은 장면이 **3/14에서 11/14**로 늘었다. 전체 보행자도 8건 더 찾았다. 다만 120장의 엄격한 사람 오검출은 3건에서 9건으로 늘어 허용 상한 4건을 넘었다. **확대 후보는 개발 기준 미통과**이며 기존 모델을 유지한다. 새 독립 보류 장소는 사용하지 않았다. [고정한 규칙](protocol.json) · [전체 지표와 판정](result.json)

## 추가 추론 비용

RTX 3090 한 장에서 CUDA ONNX Runtime을 사용했다. 디코딩된 RGB가 준비된 순간부터 전체 영상 전처리·추론·후처리, 필요 시 확대 영역 자르기·두 번째 추론·검출 병합까지 측정했다. 각 프레임의 첫 추론을 기준으로 추가 시간을 짝지어 계산했다. 모델 초기 로딩, PNG 읽기, 카메라 대기, CARLA 및 제어 전달은 측정 범위 밖이다.

| 자료 | 확대 실행 | 확대 실행 시 추가 시간 평균 / P95 | 전체 프레임 평균 (기존 → 확대) | 전체 프레임 P95 (기존 → 확대) |
| --- | ---: | ---: | ---: | ---: |
| 기존 검증 | 77/699 (11.0%) | 30.1 / 33.6ms | 33.2 → 36.5ms | 37.1 → 59.7ms |
| Town02 2K | 34/120 (28.3%) | 30.5 / 30.7ms | 41.6 → 50.2ms | 42.3 → 72.1ms |

Town02에서 확대한 34장의 최종 처리 시간은 평균 72.0ms, 확대하지 않은 86장은 평균 41.6ms였다. 확대한 프레임의 추가 30.5ms 중 두 번째 ONNX Runtime 호출이 평균 22.1ms를 차지했다. 이 호출 시간은 CPU 결과 반환까지 포함한다. 측정한 819장 중 RGB 처리 시간 100ms 이상은 0장이었다. Jetson 및 동시 제어 실행의 지연은 별도 측정 대상이다. [기존 검증 프레임별 기록](archive-validation.jsonl.gz) · [Town02 프레임별 기록](pairs-validation.jsonl.gz)

## 절차와 다음 비교

후보 규칙과 판정 기준을 커밋 `cca36afa`에서 검증 전에 고정했다. 이륜차 검출 중 점수가 가장 높은 한 대 주위에서 원본 가로·세로의 3/8을 잘라 같은 모델에 입력한다. 2560×1536에서는 960×576이다. 1280×768 및 640×384 검증 영상에는 같은 화각 비율을 사용했다. 사람 기준은 0.60이다. Town01 학습 120장에서는 기존 확대 실험의 검출·오검출·확대 발생 횟수가 재현됐다. 첫 검증 실행 후 비교기의 기존 지표 필드명을 수정해 같은 후보로 전체를 재생했다. 819장 모두 두 실행의 확대 영역, 검출 개수, 프레임별 정답 대응이 일치했다.

후속 가능성을 확인하려고 **학습 자료에서만** 추가 검출 박스의 크기를 원본 평가 좌표로 환산했다. 기존 최소 크기(짧은 변 4픽셀, 면적 25픽셀)에도 못 미치는 박스 4건을 표시했다. 이들을 따로 세면 엄격 오검출이 6건에서 2건으로 줄고 두 사람 동시 검출은 10/14였다. 박스 면적만으로 실제 마스크의 가시 면적을 확정할 수는 없다. 다음 단계에서는 작은 사람의 원래 검출을 보존하고, 별도로 부여한 크기 표시가 정답 크기를 얼마나 정확히 구별하는지 새 개발 자료에서 확인한다. 이번 검증의 엄격한 판정에는 모든 검출을 포함했다.

## 재현

로컬의 동결 모델, 기존 검증·학습 자료, RTX 3090 CUDA 환경을 사용한다. 기록에는 프레임별 RGB 해시·확대 좌표·검출 좌표·점수·단계별 시간이 들어 있다. 두 실행의 지연은 각각 실측값이다.

```bash
py=build/m10-perception/cuda-venv/bin/python
src=tests/integration/perception
out=build/m10-person-zoom-replay
export PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
"$py" "$src/person_zoom_validation.py" "$out/parity" --training-parity
"$py" "$src/person_zoom_validation.py" "$out/first"
"$py" "$src/person_zoom_validation.py" "$out/second"
"$py" "$src/person_zoom_audit.py" "$out/first" "$out/second" "$out/parity" "$out/audit.json"
```
