# M10 원본 사람 검출을 유지하는 확대 추론

전체 영상의 사람 박스를 유지한 상태에서, 확대 영상에서 별개로 관측한 사람만 추가한다. 같은 D-FINE 가중치를 두 관측에 사용한다. 640×384 환산 짧은 변이 4픽셀 이상이고 면적이 25픽셀 이상이며 신뢰도가 0.85 이상이어야 추가할 수 있다. 점수가 높은 관측부터 처리하며, 이미 유지한 사람 박스 중 하나와 IoU가 0.50 이상이면 추가하지 않는다. 다른 클래스는 전체 영상에서 처리한다.

Town01만 사용한 첫 선택은 새 Town05에서 탑승자와 동시 검출을 각각 한 건 늘렸지만 보행자 수가 30/52에 머물러 기각했다. 다음 선택에는 이미 결과를 본 Town01·Town02·첫 Town05를 개발 자료로 사용했다. 세 곳 모두에서 기존 조건을 충족한 설정 23개 중 보행자 검출 증가가 가장 작은 도로의 개선량부터 비교했다. 커밋 `b9278c7f`에서 선택값과 추가 도로 검증 기준을 고정했다. ## 독립 도로 검증과 최종 보류 평가

추가 Town05 도로 34·52의 120장에서 보행자는 33/52에서 41/52, 탑승자는 45/48에서 46/48, 동시 검출은 1/16에서 10/16으로 늘었다. 두 방식 모두 사람 오검출은 0건이었다. 다섯 기준을 모두 통과한 뒤 장소 307의 평가 모델과 조건을 고정했다. [독립 도로 검증](replication.json) · [보류 평가 사전 기록](nomination.json)

**장소 307의 81장 최종 판정은 FAIL이다.** 절대 기준 중 버스 재현율 하나가 미달했다. YOLOX-S 대비 상대 기준 여섯 항목은 모두 통과했다. 같은 2K 영상에서 후보는 전체 정답 129개 중 113개를 찾아 정밀도 95.76%, 재현율 87.60%를 기록했다. YOLOX-S는 77개를 찾아 정밀도 65.25%, 재현율 59.69%였다. 평가 전 영상 48,822개의 RGB 해시와 일치하는 프레임은 없었다. [최종 판정](result.json) · [전체 채점표](evaluation-holdout-01-score.json)
