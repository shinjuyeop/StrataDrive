# 미검출 승용차 복구 평가

도로 57에서 승용차 재현율은 동일 영상 기준 31/33에서 33/33으로 올랐다. 전체 영상의 YOLOX-S 승용차 후보(0.35 이상)를 별도 확대 영상의 D-FINE 또는 YOLOX-S가 승용차로 확인(0.65 이상)하고, 기존 물체와 겹치는 중복 후보를 제거했다. 개발 도로 네 곳과 기존 검증 699장, 실제 승용차 박스를 출력에서 하나씩 제거한 개발 대조 검사로 두 값을 정했다. [개발 점수와 선택](selection.json) · [도로 57 결과](previous57.json)
