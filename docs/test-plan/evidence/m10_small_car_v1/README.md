# 확대 영역 간 승용차 일치 검사

개발 도로 네 곳과 이전 검증 699장에서 같은 승용차를 서로 다른 확대 창이 0.95 이상으로 검출할 때 추가하는 설정을 선택했다. 개발 자료에서 정검출은 2,088건에서 2,091건으로, 오검출은 209건에서 210건으로 바뀌었다. [개발 결과](selection.json)

도로 55의 동일 영상에서 전체 재현율은 155/198(78.28%)에서 167/198(84.34%)로 올랐다. 총 오검출은 9건이었다. 도로 57에서는 작은 배경 차량의 추정 박스가 실제로 보이는 마스크보다 커서 음성 장면에서도 검출을 추가했다. 원래 YOLOX-S 비교에서는 음성 오검출 증가가 허용되지 않아 후보를 기각했다. 이 후보는 도로 60의 평가 촬영을 진행하지 않았다.
