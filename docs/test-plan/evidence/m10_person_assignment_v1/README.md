# M10 보행자·탑승자 박스 일대일 대응 실험

**일대일 대응 후보를 기각했다.** Town02의 이륜차 중첩 장면 중 보행자와 탑승자 모두 평가 크기를 충족한 14장에서 두 사람을 함께 검출한 횟수는 기존 모델과 후보 모두 3건이었다. 보행자만 세면 양쪽 모두 4/14였다. 새 보류 장소는 사용하지 않았다. [사전 비교 기준](protocol.json) · [검증 결과](result.json)

| 검증 집합 | 보행자 정검출 (기존 → 후보) | 탑승자 정검출 (기존 → 후보) | 사람 오검출 (기존 → 후보) |
| --- | ---: | ---: | ---: |
| 기존 699장 | 55/60 → 55/60 | 85/101 → 85/101 | 3 → 4 |
| Town02 120장 | 30/46 → 30/46 | 46/48 → 46/48 | 3 → 3 |

Town02의 이륜차 뒤에서 놓친 보행자 10건 중 9건에는 보정 후 정답과 IoU 0.50 이상 겹치는 박스가 있었지만 점수가 모두 0.60 미만이었다. 나머지 1건은 입력 후보와 보정 결과 양쪽에 일치하는 박스가 없었다. 이 10건에서 중복 제거 단계까지 도달한 일치 박스는 0건이었다.

## 학습과 검증

기존 학습 1,461장과 Town01 120장에서 동결된 D-FINE의 박스 좌표를 회귀 보정했다. 각 정답에 후보 하나를 배정하고 남은 중복 박스 3,252개와 위치가 부정확한 박스 2,311개를 오답으로 학습했다. 보행자·탑승자 구분은 마스크의 의미 태그에서 얻었다. 추론에서는 RGB로 얻은 특징과 후보 박스 사이의 겹침 정도를 사용했다. 기존 검출을 유지하고 추가 박스에 점수 기준 0.60을 적용했다. 후보의 판정 기준과 가중치 해시를 커밋 `1ace9ab8`에서 고정한 뒤 검증했다. 같은 환경에서 다시 학습한 모델의 해시가 일치했다. [학습 기록](fit.json)

## 원본 해상도의 국소 확대 실험

검증 결과를 본 뒤 Town01 **학습 영상에서만** 기존 모델의 입력을 바꿔 비교했다. 첫 추론에서 검출한 이륜차 한 대를 중심으로 2560×1536 원본 중 960×576 영역을 잘라 같은 모델에 한 번 더 입력했다. 확대 영역 안의 사람 검출을 원래 좌표계로 되돌렸고 전체 시야와 동일한 정답 및 점수 기준으로 채점했다. 120장 중 39장에서 추가 추론했다.

두 사람이 모두 평가 가능한 이륜차 중첩 장면 14장에서는 기존 1장에서 **확대 후 10장**으로 동시 검출이 늘었다. 전체 학습 120장에서 보행자 검출은 24/46에서 33/46, 탑승자는 48/48에서 48/48, 사람 오검출은 1건에서 6건이 됐다. 확대 후 오검출 6건 모두 실제 사람의 작은 마스크와 IoU 0.50 이상 겹쳤다. 이 마스크들은 원래 평가의 최소 가시 크기에 미달해 엄격한 채점에서 오검출로 센다. 다음 비교에서도 이 수치를 그대로 보고하고, 작은 사람을 검출한 횟수를 함께 기록한다. 독립 검증 품질과 추가 추론에 따른 지연은 미측정이다. [학습 영상 확대 결과](train-zoom.json)

## 재현

저장소 루트에서 기존 2K 촬영 원본과 특징 캐시를 사용한다. 모델은 로컬 출력 폴더의 `model.joblib`에 저장된다. 실행 환경은 NumPy 1.23.5, SciPy 1.8.0, scikit-learn 1.1.3이다.

```bash
py=build/m10-perception/cuda-venv/bin/python
src=tests/integration/perception
out=build/m10-person-assignment-v1
export PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
"$py" "$src/person_assignment_candidate.py" fit "$out"
"$py" "$src/person_assignment_candidate.py" evaluate "$out"
"$py" "$src/person_assignment_crop_probe.py" "$out/train-zoom.json"
```
