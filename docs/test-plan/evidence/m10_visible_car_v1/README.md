# 소형 승용차의 가시 면적 검증

네 개발 도로의 RGB 검출과 원본 인스턴스 마스크 306개 관측에서 보이는 면적과 박스의 짧은 변의 비율을 추정했다. 새 승용차 박스에는 가시 면적 비율 0.3235, 짧은 변 비율 0.9691을 적용하고 원래 25픽셀·4픽셀 기준을 확인했다. 개발 자료의 실제 정검출은 타일 복구 전보다 3건 늘었다. [보정값과 개발 점수](selection.json)

같은 후보는 과거 아홉 장소 각각의 원본에서 절대·상대 기준을 모두 통과했다. 도로 55에서 전체 재현율은 155/198에서 159/198(80.30%)이 되었고, 도로 57의 추가 음성 오검출은 0건이 됐다. [도로 55](previous55.json) · [도로 57](previous57.json)

새 도로 60의 81장에서 정밀도와 재현율은 각각 93.80%였다. 절대 기준 9개와 YOLOX-S 상대 기준 5개를 통과했다. 정면 버스 두 장에서 YOLOX-S가 찾은 버스를 최종 후보가 놓쳐, 버스 검출 13/15가 같은 영상의 YOLOX-S 15/15보다 낮았다. 최종 후보는 첫 장에서 트럭만 출력했고 둘째 장에서 차량 박스를 출력하지 않았다. [새 도로 전체 점수](holdout.json) · [프레임별 검출](holdout-detections.json.gz)
